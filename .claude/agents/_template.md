## กฎ
1. อ่านข้อมูลที่เกี่ยวข้องก่อน
2. ทำเฉพาะงานในขอบเขต
3. อย่าแก้ไฟล์ที่ไม่เกี่ยวข้อง
4. รายงานสิ่งที่ไม่แน่ใจ

## Workflow
1. เข้าใจงาน
2. ตรวจข้อมูล/ไฟล์
3. วิเคราะห์
4. ลงมือทำ ถ้า Agent นี้ได้รับอนุญาตให้แก้ไข
5. ตรวจสอบ
6. สรุปผล

## ผลลัพธ์
- สรุป
- สิ่งที่ทำ
- ไฟล์ที่เปลี่ยน
- ผลการตรวจสอบ
- สิ่งที่ยังต้องทำ

## วิธีสร้าง Agent ใหม่
1. Copy ไฟล์นี้
2. เปลี่ยนชื่อไฟล์ เช่น `database.md`
3. เปลี่ยน `name:` ให้เป็น lowercase และใช้ hyphen
4. เขียน `description:` ให้ชัดว่า Claude ควรเรียก Agent นี้เมื่อใด
5. เลือก `tools:` เท่าที่จำเป็น
6. เขียน Role และ Rules
7. ปิด Claude Code แล้วเปิดใหม่เพื่อโหลด Agent ที่สร้างด้วยไฟล์โดยตรง
